# Skills de trabalho da PGAE

Procedimentos repetíveis para o Claude Code. Cada pasta tem um `SKILL.md`.

| :--- | :--- |

| [nova-funcionalidade](nova-funcionalidade/SKILL.md) | Implementar uma funcionalidade de uma fase do roadmap, de ponta a ponta |
| [checklist-seguranca](checklist-seguranca/SKILL.md) | Verificação de segurança antes de abrir/fundir um PR |
| [migracao-bd](migracao-bd/SKILL.md) | Alterar o esquema da base de dados com segurança |
| [release-de-fase](release-de-fase/SKILL.md) | Fechar uma fase: PR de release, tag, GitHub Release, deploy |
